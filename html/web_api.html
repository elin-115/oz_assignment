Web API

  • 1. DOM API

    document.querySelector, element.textContent

  • 2. Event API

    addEventListener

  • 3. Timer API

    setTimeout, setInterval

  • 4. Storage API

    localStorage, sessionStorage

  • 5. Fetch API

    서버와 통신 (fetch)

Timer API

① setTimeout

일정 시간이 지난 뒤에 함수를 한 번 실행하는 Web API

② setInterval

일정 시간마다 함수를 반복 실행하는 Web API

Storage API

- 브라우저가 제공하는 클라이언트 측 저장소(Web API)

- 서버 없이도 데이터를 브라우저에 저장/조회

특징
  • 키(key) / 값(value) 형태로 데이터 저장
  • 값은 문자열(string)로 저장
  • 페이지 새로고침 후에도 유지

① localStorage

민감하지않은 정보만 넣어야 한다

  • 영구 저장(브라우저를 껐다 켜도 남아 있음)
  • 로그인 정보, 설정값 저장에 사용
  • 만료 시간 없음

② sessionStorage

  • 세션 단위 저장(브라우저(탭) 닫으면 삭제)
  • 임시 데이터
  • 같은 사이트라도 탭마다 별도

Fetch API

- 서버와 통신 (fetch)

- 브라우저가 제공하는 서버 통신용 Web API

- 서버에 HTTP 요청을 보낼 수 있도록 도와주는 API

  • HTTP 요청(Request)을 보내고 응답(Response)을 수신
  • 비동기로 동작
비동기(Asyncronous)
  • 오래 걸리는 작업을 기다리지 않고, 다음 코드를 먼저 실행하는 방식(=일시정지)
  • 서버 요청은 시간이 걸리기 때문에 요청은 보내고, 다른 작업을 계속 진행
  • fetch는 서버에 요청을 보내고, 응답이 오면 그때 결과를 처리
