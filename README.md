# oz_assignment

HTML · CSS 기초를 학습하며 작성한 정리 문서와 실습 파일 모음입니다.

## Index

| 순서 | 문서 | 내용 |
| --- | --- | --- |
| 1 | [HTML.md](HTML.md) | HTML 기초 문법 정리와 `html/` 폴더 실습 파일 설명 |
| 2 | [CSS.md](CSS.md) | CSS 기초 정리: 셀렉터, 박스 모델, position, Flexbox, 반응형, Grid |
| 3 | [resume_v1.html](resume_v1.html) | 이력서 페이지 v1: HTML 기초 태그(목록, 표, 폼)와 외부 CSS 적용 |
| 4 | [resume_v2.html](resume_v2.html) | 이력서 페이지 v2: 고정 헤더 · 사이드바 레이아웃, 실제 이력 반영 |

## 폴더 구조

```
oz_assignment/
├── README.md
├── HTML.md             # HTML 기초 정리
├── CSS.md              # CSS 기초 정리
├── index.html          # 이력서 페이지 목록
├── resume_v1.html      # 이력서 v1
├── resume_v2.html      # 이력서 v2
├── box_model.html      # 박스 모델 실습
├── html/               # HTML 문법별 실습 파일
├── css/
│   ├── style.css         # resume_v1.html 스타일
│   └── resume_style.css  # resume_v2.html 스타일
└── images/             # 실습에 사용한 이미지
```

## 실행 방법

각 `.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

```bash
open resume_v2.html
```
